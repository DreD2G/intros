# Git & GitHub Practice Repo

Welcome! This repo is just markdown files — no code, no setup beyond Git and VS Code. The goal is to practice the actual workflow you'll use for your Blue project all semester.

## Today's exercise

1. **Clone this repo** to your computer
2. **Open it in VS Code**
3. **Create a branch**, named after yourself (e.g. `add-jamie`)
4. Inside the `Submissions/` folder, **add a new file** called `your-name.md` (see format below)
5. **Commit** your change and **push** your branch
6. **Open a Pull Request**
7. **Swap with a partner** — review each other's PR and leave at least one comment

No formal deliverable — we're practicing the workflow together, live.

## Your intro file

Create `Submissions/your-name.md` using this format:

```markdown
# Your Name

**Year & major:**

**Fun fact:**

**Something I want to build this semester:**
```

Everyone gets their own file, so there's no risk of stepping on anyone else's work.

## Command cheat sheet

```
git checkout -b add-your-name         # create + switch to your branch
git add Submissions/your-name.md      # stage your new file
git commit -m "Add my intro"          # save a snapshot
git push                              # upload your branch to GitHub
```

Then head to GitHub to open your Pull Request.

## Stuck?

- `git status` — see what's changed and what's staged
- Ask your neighbor before asking your instructor — you're each other's first resource today
